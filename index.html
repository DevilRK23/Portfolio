This pipeline scans incoming traffic packet anomalies via dynamic scoring, rate-limiting rules, and temporary socket locks.

Reads headers, payload size, source IPs, and connection rates.

2. Anomaly Scoring

Evaluates traffic with Isolation Forest algorithm models trained in Scikit-learn.

3. Rate-Limiting Filter

Enforces dynamic request-limit thresholds on suspected endpoint vectors.

4. Firewall Blocking

Locks malicious sockets and updates security routing logs automatically.
